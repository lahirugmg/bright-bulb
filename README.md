# Bright Bulb

Website for the **Bright Bulb** Facebook page: bite-sized science, technology, nature, history and big ideas for an English-reading audience. Sister page to the Sinhala page [සිතන දැනුම](https://www.facebook.com/sithanadanuma/).

Plain HTML, CSS and JavaScript, hosted on GitHub Pages. No build step.

## Editing

- **Facebook link:** set `FACEBOOK_PAGE_URL` at the top of `script.js`.
- **Questions on the home page:** edit the `QUESTIONS` list in `script.js`. Each entry needs a `topic` (Science, Technology, Nature, History or Ideas), a question `q` and an answer `a`.
- **Text and sections:** `index.html`. **Colours and fonts:** the variables at the top of `styles.css`.

Commit to `main` and GitHub Pages republishes within a minute or two.
